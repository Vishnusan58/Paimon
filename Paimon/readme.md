# Paimon AI - Your Emergency Companion ✨

## Introduction

Paimon AI is a stylish desktop assistant application that brings a helpful AI companion to your Windows computer. Inspired by the beloved character from Genshin Impact, Paimon AI features a modern glassmorphism UI with a friendly chat interface that floats elegantly on your desktop.

This application allows you to interact with an AI assistant through text, get responses in a conversational format, and even have Paimon speak responses through voice synthesis.

## Features

- **Elegant Glassmorphism UI** - Beautiful transparent interface with purple glow effects
- **Floating Window** - Always stays on top of other applications (toggleable)
- **Multiple Input Methods**:
    - Direct text input
    - Full screen capture analysis
    - Selection capture for targeted questions
- **Voice Synthesis** - Paimon can speak responses aloud
- **Easy Copy Functions** - Copy individual messages or entire conversations
- **Draggable & Resizable** - Position anywhere on your screen

## Installation

1. **Download** the latest release from the [Releases](https://github.com/Vishnusan58/PaimonAI/releases) page
2. **Extract** the ZIP file to a folder of your choice
3. **Run** `Paimon.exe` to start the application

No installation required - Paimon AI runs as a portable application.

## How to Use

### Basic Usage

1. **Start** Paimon AI by running the executable
2. **Type** your question or request in the text box at the bottom
3. **Send** by pressing Enter or clicking the "Send" button
4. **View** Paimon's response in the chat area

### Special Functions

- **📌 Pin Button** - Toggle always-on-top mode
- **🔊 Voice Toggle** - Enable/disable voice responses
- **📋 Copy All** - Copy the entire conversation to clipboard
- **📄 Copy** - Copy an individual message
- **🖥️ Full** - Analyze your entire screen for context-aware answers
- **🎯 Select** - Analyze only a selected portion of your screen

### Keyboard Shortcuts

- **Enter** - Send message
- **Shift+Enter** - Add a new line in your message
- **Esc** - Close the application

## System Requirements

- Windows 10 or newer
- .NET Framework 4.7.2 or higher
- 4GB RAM recommended
- Internet connection for AI functionality
